# CONTROL DE COBRO PARQUEADERO 🅿️
Esta app nos permite registrar datos como placa del vehiculo, elegir entre tres tipos de vehiculos (moto 🏍️, automovil🚗 y camioneta🚙), el tiempo que estuvo estacionado.
Con estos datos la aplicacion se encarga de indicar el cobro que se debe hacer asi como muestra el descuento realizado y el valor base sin el descuento.

## 📈 Escalabilidad de la App
Facilmente podemos agregar mas tipos de vehiculos, añadiendo mas checkbox en la interfaz principal de la app. También validar diferentes tipos de descuentos segun lo requiera el usuario

 *📅 Descuento mensual
 
 *🚗💳 Descuento por pago anticipado
 
 *🧓 Descuento para adultos mayores
